# 📷 ZaBir Image Editor

**ZaBir Image Editor** is a desktop image editing application built with Python, Tkinter, Pillow, and NumPy. It provides a simple, modern interface for viewing, editing, transforming, and saving images.

## ✨ Features

- **Image Management:** Open and save images in multiple formats.
- **Image Adjustments:** Brightness, contrast, exposure, highlights, shadows, saturation, temperature, vibrance, sharpness, clarity, and vignette.
- **Transform Tools:** Rotate, flip, and crop images.
- **Zoom & Navigation:** Zoom in, zoom out, and move images using the mouse.
- **Undo & Redo:** Restore previous image states.
- **Reset Controls:** Reset adjustments or restore the original image.
- **Modern UI:** Cream-white theme with a scrollable editing panel.
- **Keyboard Shortcuts:** `Ctrl + O` to open, `Ctrl + S` to save, and `Esc` to cancel cropping.

## 🛠️ Technologies Used

- Python
- Tkinter
- Pillow (PIL)
- NumPy

## 🚀 Usage

1. Click **Open Image** to select a picture.
2. Adjust the editing sliders as needed.
3. Use the transform tools to rotate, flip, or crop the image.
4. Use Undo or Redo to manage changes.
5. Click **Save Image** to export your edited picture.
